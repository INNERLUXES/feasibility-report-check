# Feasibility study: parcel locker booking for Harbour Lane Couriers

Written by the delivery platform team for the operations board.

## Verdict

Go with changes. The service can be built and run inside the budget if label printing moves to a second release and
the locker vendor signs the data processing terms before the build starts.

## Summary

| Angle | Rating |
| --- | --- |
| Technical | Feasible |
| Financial | Feasible with conditions |
| Operational | Amber |
| Schedule | Feasible |
| Legal | At risk |
| Security | Feasible |

Customers who miss a home delivery today wait for a second attempt or travel to a depot during opening hours. Lockers
at the depots would let them collect a parcel at any hour with a one-time code.
