# A good report

A made-up feasibility study for a parcel locker booking service at a made-up courier, Harbour Lane Couriers, written
by a made-up delivery platform team. The report is split into four files that are read in the order of their names as
one report; this README is not part of it.

It gives a verdict, covers the five default angles and a security angle, each with a rating, lists its risks with a
response and an owner, lists its assumptions with how each was tested, gives its costs and times as ranges, reports
what its prototype showed and could not show, and ends with next steps. The tool finds nothing in it, with the
built-in configuration and with `examples/config.json`.
